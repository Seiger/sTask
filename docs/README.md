# sTask Documentation

sTask is the Evolution CMS background task manager for queued jobs, worker
configuration, task logs, progress tracking, uploads, downloads, and operational
maintenance tasks.

These localized filesystem docs are the preferred dDocs entrypoint. The Ukrainian
tree is the canonical, code-audited sTask 2.x guide. The older Docusaurus site is
kept under `website/`, outside the recursively indexed dDocs source tree, and must
not be treated as the current runtime contract.

## Coverage

Every language tree contains the complete guide: installation, lifecycle and
schedules, supervisor state, all five EvoUI manager tabs, public PHP extension
points, manager routes, progress files, database schema, production operations,
troubleshooting, and the 1.x to 2.x review checklist. Ukrainian remains the
canonical source for future synchronization. Machine-readable inventory lives
in `docs.json`.
