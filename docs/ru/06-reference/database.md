# Таблицы базы данных

Ниже приведены фактические миграции схем ветви 2.x.

## `s_workers`

| Колонка | Тип/атрибуты | Цель |
| --- | --- | --- |
| `id` | BIGINT PK | внутренний идентификатор работника |
| `uuid` | UUID nullable unique | Опциональная внешняя идентичность |
| `identifier` | String unique | Ключ маршрутизации стабильной задачи |
| `scope` | Строка по умолчанию `''` | Группировка пакетов/модулей |
| `class` | строка | FQCN |
| `active` | Булева стандартная ложь | Планировщик/Run Gate |
| `position` | Неподписанный интеллект по умолчанию 0 | Порядок интерфейса |
| `settings` | Стандартное выражение пустого массива JSON | Расписание/пользовательские настройки |
| `hidden` | Неподписанный интеллект по умолчанию 0 | Видимость интерфейса |
| Временные метки | создано/обновлено | Аудит |

Индексы: уникальный uuid, уникальный идентификатор, плюс идентификатор, область действия, индексы позиций. Уникальный идентификатор уже создаёт индекс; дополнительный явный индекс может быть избыточным в зависимости от базы данных.

## `s_tasks`

| Колонка | Тип/атрибуты | Цель |
| --- | --- | --- |
| `id` | BIGINT PK | ID задачи |
| `identifier` | строка | Ключ маршрутизации рабочего |
| `action` | строка | Кодекс действий |
| `status` | неподписанный малый int по умолчанию 10 | Жизненный цикл |
| `message` | Текст обнулируемый | Сохраняющееся резюме/ошибка |
| `started_by` | Незнаковое int nullable | менеджер пользователя или системы |
| `meta` | longText nullable | Входные метаданные |
| `result` | longText nullable | результат полезной нагрузки/пути |
| `start_at` | временная метка обнулируемая | Запланированный/фактический старт |
| `finished_at` | временная метка обнулируемая | последний раз |
| `attempts` | int по умолчанию 0 | Постепенно при запуске |
| `max_attempts` | int default 3 | Повтор метаданных |
| `priority` | строка по умолчанию нормаль | Совместимость/порядок очереди |
| `progress` | int по умолчанию 0 | Устойчивый прогресс |
| Временные метки | создано/обновлено | Аудит |

Индексы: `(identifier, action)`, статус, started_by, start_at, created_at, приоритет.

Нет внешнего ключа от идентификатора задачи к `s_workers.identifier`, поэтому история сохраняется после удаления записи работника. Отношение логически работает по идентификатору.

Meta/result превращает модель Eloquent в виде массива; на самом деле хранение — это длинный текст, а не родной JSON.

## `s_supervisor_states`

| Колонка | Тип/атрибуты | Цель |
| --- | --- | --- |
| `id` | BIGINT PK | идентификатор строки штата |
| `worker_id` | неподписанный BIGINT, индексированный | Владелец `s_workers.id` без FK |
| `identifier` | строка, индексированная | денормализованный рабочий ключ |
| `supervisor_key` | строка | Идентификация процесса адаптера |
| `key_hash` | char(64) уникальный | Идентификатор работника sha256 + ключ |
| `state` | string(24), по умолчанию остановлен, индексирован | Состояние жизненного цикла |
| `pid` | неподписанный BIGINT nullable | ID процесса |
| `heartbeat_at` | временная метка обнулируемая | Последний удар сердца |
| `supervisor_started_at` | временная метка обнулируемая | Начало процесса |
| `uptime_seconds` | неподписанный BIGINT nullable | Время безработной работы адаптера |
| `message` | Текст обнулируемый | Диагностика |
| `fingerprint` | char(64) nullable | dedup отпечаток пальца |
| `last_transition_at` | временная метка обнулируемая | Переход состояния |
| `last_seen_at` | временная метка обнулируемая, индексируемая | Последнее наблюдение планировщика |
| `repeat_count` | Неподписанный интеллект по умолчанию 0 | повторяющийся подсчёт отпечатков пальцев |
| `launch_requested_at` | временная метка обнулируемая | Курсор Запуска Благодати |
| Временные метки | создано/обновлено | Аудит записей |

### Жизненный цикл

`firstOrNew(key_hash)` гарантирует одну живую строку на каждый рабочий ID + стабильный ключ. Каждый проход обновляет последнюю видимость; Тот же отпечаток увеличивает количество повторов, новый отпечаток сбрасывает его до нуля. Обновления перехода состояния `last_transition_at`.

Здоровый статус очищает `launch_requested_at`. Другие статусы сохраняют предыдущий или текущий запрос на запуск.

### Рост и очищение

История сердцебиения не накапливает строк. Рост означает новые удостоверения или ключи работников. Нет автоматического удержания, нет внешнего ключа/каскада.

Безопасная уборка:

1. инвентаризацию фактических работников и ключей адаптеров;
2. Убедитесь, что Daemon with Old Key не работает;
3. архивная диагностика при необходимости;
4. Удалить только точные сиротские идентификаторы/хеши.

Не делайте широкие `TRUNCATE` во время активного планирования.

## Таблицы разрешений

Миграция, если существуют системные таблицы:

- находит/создаёт группу `sTask`;
- разрешение upsert-it `stask` с `disabled = 0`;
- добавляет role_permissions для роли `1`;
- на PostgreSQL может восстанавливать последовательность после конфликта вставки.

Миграция отключает обёртку транзакций Laravel, потому что PostgreSQL прерывает транзакцию после неудачного оператора, и код имеет путь повторной попытки.

## Портативность

Схема ориентирована на MySQL/MariaDB/PostgreSQL/SQLite через Laravel Schema Builder. Стандартное выражение JSON `JSON_ARRAY()` чувствительно к базе данных; Запустите миграционные тесты на целевом движке. Миграция разрешения обрабатывает последовательность PostgreSQL отдельно.
