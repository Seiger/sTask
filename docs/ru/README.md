# sTask 2.x

sTask — пакет Evolution CMS для управления фоновыми задачами. Он хранит очередь в базе данных, находит воркеры через Composer, запускает их командой `stask:worker`, показывает прогресс и логи в менеджере, а также отдельно контролирует долгоживущие supervisor-процессы.

Документация описывает фактическую ветвь `2.x`. Она не предполагает наличия внешней очереди, SSE или WebSocket: live progress в менеджере считывается периодическими HTTP-запросами из файловых логов `storage/stask/{taskId}.log`.

## Для кого эта документация

- **Администратор** — установка, права доступа, cron, вкладки менеджера, диагностика и production-эксплуатация.
- **Интегратор** — расписания, регистрация воркеров, маршруты менеджера, миграции и обновления.
- **PHP-разработчик** — `TaskInterface`, `BaseWorker`, фасад `sTask`, прогресс API и контракт супервайзера.

## Пределы ответственности

sTask выполняет работника последовательно в процессе `stask:worker`. Пакет не предоставляет одноразовую гарантию распределенного брокера, автоматического завершения процесса ОС с помощью аварийной кнопки остановки или хранения всех сообщений о прогрессе в базе данных. Такие требования реализуются сотрудником приложений и инфраструктурой проекта.

## Первая проверка

После установки выполните:

```bash
cd core
php artisan migrate
php artisan package:discover
php artisan stask:publish
php artisan stask:worker
```

Ожидаемый результат: были созданы миграции `s_workers`, `s_tasks` и `s_supervisor_states`, публиковались пакетные активы, а рабочая команда завершала сообщением о числе созданных и обработанных задач. Далее откройте модуль **sTask** в менеджере.
